# 六类能力案例的合成测试素材

本目录只包含自造数据与绘图，不含真实账单、联系人或支付记录。文件名与案例编号相对应。

工具06—10另有[按编号整理的文件与使用说明](../工具06-10/README.md)及[ZIP下载包](https://github.com/lwh0912/xiaowei_AI/raw/refs/heads/main/测试素材/工具06-10测试素材.zip)，可解压后直接选取对应输入。

| 案例 | 输入素材 | 用法 |
| --- | --- | --- |
| TOL06 | 测试流水.csv | 上传原始表格；无文件能力时可粘贴表格作对话入口对照，需另记入口 |
| TOL07 | 取件说明.txt | 文件内含一条待分析的命令式引文，用于检查数据与指令的边界 |
| TOL08 | 方案_v1.txt、方案_v2.txt、方案_v2_备注.txt | 按案例指定顺序上传，明确主文件与备注的角色 |
| TOL09 | [提醒操作话术.txt](../工具06-10/TOL09/提醒操作话术.txt) | 不上传文件，逐轮复制话术并手动核对提醒列表 |
| TOL10 | 明细.csv、名称.csv | 编码是字符串；001与1不同，不要先用软件自动转成同一数值 |
| CRT01 | 局部编辑基准.png | 白底红方块、蓝圆、绿三角与P7；用于局部修改后核对非目标区域 |
| CRT07 | 卡片_A红.png、卡片_B蓝.png、卡片_C绿.png、卡片_A黄.png | 先传前三张，待案例要求替换时再传黄底A |

核对答案见[测试者核对答案](./核对答案.md)。不要把答案和原始材料一起发送给小微。

其余案例多数直接给出可复制的合成文本。联系人、聊天、收藏、笔记、提醒、视频号等真实入口，仍需根据案例前提由测试者在自控环境准备。本目录没有代建这些账号内容。

CON06若测试视频号，需要事先制作并放到允许测试的入口。按案例准备9秒视频：0—3秒蓝圆形，3—6秒绿色正方形，6—9秒紫色星形；各段字幕对应形状，无音轨，无橙色三角形，标题只写“形状测试”。保留原文件作为核对依据。若仅上传本地视频，不要将其结果当成视频号入口结果。
