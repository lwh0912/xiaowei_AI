可[下载整个素材包](https://github.com/lwh0912/xiaowei_AI/raw/refs/heads/main/测试素材/工具06-10测试素材.zip)，解压后按下表取文件。只上传当前案例列出的输入文件，不把ZIP、整个文件夹或核对答案交给小微。单独下载GitHub中的TXT/CSV时，打开文件页面并使用“Download raw file”，避免把网页另存为输入文件。

## 执行时注意

- CSV/TXT均为UTF-8编码。CSV是输入数据，不含计算答案或额外汇总行。
- TOL10中`001`、`1`、`A01`是三个不同的文本编码。直接使用原始CSV上传；若先在Excel等软件里编辑并保存，需把编码列明确导入为文本，避免前导零被提前改掉。不要用公式`="001"`替代原始编码。
- TOL09默认日期为2027年6月1日，时间按北京时间（UTC+8）。如果执行时日期已过期，把所有轮次整体改为同一个明确未来日期；不要只改第一轮。每轮等回复后继续，并按产品要求完成确认。先记录已有同名提醒，避免误操作既有任务；结束后清理本次测试创建的提醒。
- 文件入口暂不支持某格式时，记录实际能力范围。粘贴文本可做对照，但需另记入口，不能视为文件读取已通过。

完整步骤见仓库“六类能力测试案例/工具.md”。核对答案位于“测试素材/六类能力/核对答案.md”，仅供测试者自己查看，未打入此素材包。
