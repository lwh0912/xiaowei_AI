# C 图片与多模态测试方案

本类按参赛指南2.1节的C类归档，辅助能力标签用于说明任务链。全部为待执行方案，满意度待评，不是已发现缺陷。P0/P1/P2表示建议执行顺序，不表示严重程度。只把原始素材和对应话术发给小微，核对答案留给测试者。

每次记录实际入口、已提供的上下文、客户端版本、权限、记忆状态及素材版本；缺少能力或素材时标“阻塞”或“不适用”，不要填失败。下列后续话术按真实回复选用，不要求逐句照抄或凑固定轮数。

| 编号 | 真实任务 | 建议顺序 | 首要观察 |
| --- | --- | --- | --- |
| PLAN-C01 | 账单识别后更新退款和分摊文案 | P0 | 最新金额是否贯穿最终产出 |
| PLAN-C02 | 海报只改地点和时间 | P1 | 修改范围与未改字段保持 |
| PLAN-C03 | 两张卡片的身份与替换对应 | P1 | 图片来源、顺序和对象绑定 |
| PLAN-C04 | 短视频总结区分画面字幕声音与标题 | P2 | 读取范围和证据来源是否诚实 |

### PLAN-C01 账单识别后更新退款和分摊文案

**分类与状态：** 主类C；辅助能力“工具、创作、社交”；状态待执行，等级待评。

**入口与上下文：** 主入口上传账单图片；若图片菜单“问小微”可用，另作入口对照。系统应获得原图、后续新增退款和明确人数；不能假设它能读取未提供的支付账单。消息只生成草稿，不实际发群或发起收款。

**前提与素材：** 已核对现成[账单核对素材.png](../测试素材/账单核对素材.png)，图中文字完整。虚构账目为A01有效25.00元；A02有效24.00元、已退12.00元；A03有效29.70元；A04已取消17.80元。图底规则写明取消单不计、有效单扣退款。图片若上传后不可读，先记录读取限制；可用同文纯文字对照，不能把文字测试当作图片入口已经通过。

**口语开场：** 发图后说：“这回活动到底花了多少钱啊，帮我算下，取消的别算。”

**随结果选用的后续变化：**

1. 正确提取后说：“哦对，A01里饮料那6块5也退了，刚收到。”
2. “先按我们仨平摊，包括我在内，按分算，别多收。”
3. “漏了小陈，算上他一共四个人，其他不变。”
4. “我垫了全部钱，帮我写两句群消息，只让另外三个人各转自己的份额，先别发。”
5. 只有实际出错时指出具体遗漏，如“你最后的文案是不是还用了没退饮料的钱？”保留纠正前后的两版。

**测试者核对依据：** 原净支出25+24−12+29.70=66.70元；追加退款后60.20元。三人可按20.07、20.07、20.06元分配，顺序可变且合计须为60.20。最终四人各15.05元；用户自己的15.05不向自己收，另外三人共转45.15元。最终文案应以四人和15.05为准，不能回到66.70、三人或把A04计入。

**候选失败与判级条件：** 先区分识别错误、退款计算错误、人数更新错误和最终文案旧值回流。一次可接受小错后迅速改正且核心办成可评B；最终应收金额实质错误、需反复沟通通常考虑C；只有充分证据满足确定性编造、虚假完成等指南红线才审D，普通算错或“我算好了”不自动等于D。完整准确且产出可用则按A/B实际表现记录。

**不报为缺陷：** 合理追问“三人是否含你”；三人分摊尾差分配顺序不同；根据明示限制无法读图并如实说明；先生成草稿待用户发送。

**复现与单变量对照：** 原样再试并写出现次数/总尝试次数。先保持其他条件只把图片换成同内容文字；另一次仅将新增退款置于分摊前或后。不能由一次对照直接断言OCR或记忆模块根因。

**独有证据：** 原图、实际上传图、退款消息、三人及四人阶段、最终草稿、逐步手算表，以及是否包含用户本人。连同入口到末轮全程截图保存。

### PLAN-C02 海报只改地点和时间

**分类与状态：** 主类C；辅助能力“创作”；P1；状态待执行，等级待评。

**入口与上下文：** 指定版本已开放的图片编辑入口或主入口传图。系统获得同一张基准海报及逐次修改要求；应记录它实际编辑的是哪一版，不能把新生成任务当成已对旧文件原位修改。

**前提与素材：** 已准备并核对[海报基准P-C02](./配套素材/海报基准_P-C02.png)，可直接上传。也可使用自己有权编辑的海报，先验收以下字段再开始。生成基线已出错时先另记初始错误，不在错误基线上断言“修改导致回退”。不需真实发布活动。

```text
海报名：翻开下一页
时间：2027年6月12日15:30
地点：A201
人数：24人
说明：带一个阅读问题即可
底部标识：测试样张 P-C02
```

**口语开场：** 发已验收基线图：“教室借不到了，只把A201换成B305，其他内容和布局尽量保留。”

**随结果选用的后续变化：**

1. 地点正确后：“时间再往后挪半小时，地点还是刚改的那间。”
2. “时间和地点的字稍微大一点，活动名、人数和底下那行别动。”
3. “把最后这版给我，我要拿手机打开看看。”实际打开返回图，不只看文字回复。
4. 若字段回退，指出具体冲突并要求只修该字段，不默认存在第五轮。

**测试者核对依据：** 最终2027-06-12 16:00、B305；标题、24人、“带一个阅读问题即可”和P-C02始终不变。以可辨认的信息及明确要求判断，不要求生成图逐像素完全相同；记录显著对象、文字、布局变化。

**候选失败与判级条件：** 已明确字段回退、文字缺失导致海报不能用，通常考虑C；轻微排版差异但信息完整、可用，可能为A/B；有清楚的真实产出时不能因回复说“改好了”直接判虚假完成。明确宣称最终图片已生成但实际任务失败且无产出时，排除仍生成、下载/缓存和折叠问题后，才按指南核验D。

**不报为缺陷：** 字体风格不合主观审美；不影响使用的轻微纹理或像素噪声；图片能力未开放并解释清楚；合理询问希望放大的区域。

**复现与单变量对照：** 相同基线重放；仅对比“先改地点再改时间”和一轮同时给最终字段。保存每版文件，不覆盖原图；如只在某版漂移，记录版本而不臆测内部原因。

**独有证据：** 已验收基线、地点版、时间版、字号版的实际图片，以及图中各字段与要求逐项对照；记录每版使用的输入图，防止误拿旧附件。

### PLAN-C03 两张卡片的身份与替换对应

**分类与状态：** 主类C；辅助能力“创作、内容”；P1；状态待执行，等级待评。

**入口与上下文：** 主入口按顺序上传两图，或指定版本支持的多图阅读入口。若入口一次只接收一图，记录限制并停止多图路径，不把未获得的第二图当作识别失败。

**前提与素材：** 已查看现成[红底A](../测试素材/六类能力/卡片_A红.png)、[蓝底B](../测试素材/六类能力/卡片_B蓝.png)、[黄底A](../测试素材/六类能力/卡片_A黄.png)。前两图分别为红底白字A、蓝底白字B；替换图为黄底黑字A。用于整理活动幻灯片的封面和附页，不涉及真实人物识别。

**口语开场：** 先发红A，再发蓝B：“帮我整理这两张素材。第一张做封面，第二张作附页，先各写一句说明，不要把图混了。”

**随结果选用的后续变化：**

1. “只说封面那张的颜色和字母。”
2. 上传黄A：“刚才的封面换成这张，附页不变，重新列一下现在两张是什么。”
3. “我想先讲附页，再讲封面。只调整展示顺序，封面和附页的身份别改。”
4. “按最终顺序给我两句解说，每句标一下对应哪张图。”生成拼图不是本案必须步骤；若另测拼图应单独记录真实产出。

**测试者核对依据：** 初始封面红A、附页蓝B；替换后封面黄A、附页仍蓝B；最后展示顺序为蓝B附页→黄A封面。红A已退出，不应同时留下三张或把“先讲”理解成替换身份。区分上传顺序、角色和最终展示顺序。

**候选失败与判级条件：** 单次轻微说法不清但澄清后角色正确可考虑B；多轮后持续把附页与封面、旧图与新图混用，最终解说实质错误通常考虑C；只有将未见的内容明确编造成“图中证据”并满足红线条件时再审D。正确承认无法确定颜色或图序而请求重发不自动判D。

**不报为缺陷：** 系统合理要求给图片命名；入口不保留多图上下文并明确说明；先说明读到了什么而非假装完成拼图。

**复现与单变量对照：** 原顺序重放；另次只交换最初上传顺序，随之重新明确角色；或保持图序，仅用文件名代替“第一张”。对照要匹配实际提供的上下文，不能拿不同信息量解释为纯入口差异。

**独有证据：** 实际上传顺序、三个原文件、角色分配、替换指令、最终顺序及解说的对应关系。初始识别错与替换后错位分别标记。

### PLAN-C04 短视频总结区分画面字幕声音与标题

**分类与状态：** 主类C；辅助能力“内容、搜索”；P2；状态待执行，等级待评。

**入口与上下文：** 已开放的视频号“问小微”；若支持上传自有视频文件，可用文件路径作对照。两者是不同入口，不能把文件分析结果当作视频号已经验证。记录实际分享内容、标题、字幕、音轨和页面说明的可访问范围。

**前提与素材：** 已准备[9秒静音视频](./配套素材/shapes_silent.mp4)，640×360、12帧/秒，无音轨；0—3秒蓝圆形，3—6秒绿正方形，6—9秒紫星形，画面字幕分别为“第一段”“第二段”“第三段”。可直接用于支持的视频文件入口；使用视频号时仍须有实际可访问的自有内容，未在本次代为发布。标题可用“形状课堂练习”，不含全部答案。[素材说明](./配套素材/README.md)含逐段核对规则。若另行添加朗读音轨，须另编号并保存真实音频内容；当前素材不能验证实际听音能力。

**口语开场：** “我想给这段课堂小视频写介绍，帮我按先后顺序说说内容，只写你实际能读到的部分。”

**随结果选用的后续变化：**

1. “你刚才哪些信息来自画面，哪些来自字幕、声音或标题？分开列一下。”
2. “我只记得中间一段，那个形状是什么？能定位的话说大概位置，不能就直说。”
3. “最后给我两句介绍，不要把没确认的内容写成确定发生了。”
4. 若实际出现了不实细节，问其依据并给机会纠正；不要预设它一定虚构，也不要把自报读取范围直接当成底层访问日志。

**测试者核对依据：** 能真实获取画面时顺序应蓝圆→绿方→紫星；仅读字幕时只能确定三段结构，字幕本身不包含形状；仅读标题时不能据此确定任一颜色或形状。当前静音素材没有可听到的朗读；若增制有声对照，按该版本实际音轨另核。时间定位允许合理近似，不要求与切帧点毫秒相等。

**候选失败与判级条件：** 在可读取范围内漏掉主要段落或顺序实质错一般先考虑C；小量遗漏且主要介绍可用可为B；明确捏造“我听到某句话/某时刻出现某物”等证据且有完整反证时，才审D档确定性编造。没有音频读取能力本身不是必然缺陷，更不能因此直接判D。

**不报为缺陷：** 登录、权限或网络导致无法访问并如实说明；只读取标题/字幕并明确局限；要求提供视频或关键片段；合理等待视频处理。

**复现与单变量对照：** 使用同一静音文件原样重放。可另制只添加朗读音轨的版本，或只调换两段画面的版本；每个变体单独更新画面/字幕/音轨核对表，不沿用原版顺序判错。视频号与文件入口仅在能确认提供的内容相同、能力范围可比时做对照。

**独有证据：** 真实上传/分享文件、逐段真值、标题与字幕、音轨有无、来源说明、定位回答和完整纠错链；保留原视频，截图覆盖完整会话，录屏仅作补充。

## 与现有方案的复用及去重

- PLAN-C01复用原OPT-016和现成账单图片；不要将同一退款旧值回流在两个方案下重复记成两类问题。
- PLAN-C02与OPT-017、CRT01相关；海报时间回退与单纯初始生字错误需要分开观察，是否同类依据最小复现和具体表现判断。
- PLAN-C03与OPT-015的选图归属、CRT07的替换映射相关；本案默认文字整理，只有另行实际生成拼图，才能评价拼图产物。
- PLAN-C04承接CON06对视频读取范围的探索；本案有声和字幕来源拆分是变体，不因换入口或标题就自动重复加分。
