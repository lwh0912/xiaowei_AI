# D 搜索与信息获取测试方案

本类按参赛指南2.1节的D类归档，覆盖搜索、文件处理与阅读；不把每一次回答错误都预判成D档。全部为待执行方案，满意度待评。P0/P1/P2为个人执行优先级，非严重程度。只给小微原始输入，不发送测试者核对答案。

| 编号 | 真实任务 | 建议顺序 | 首要观察 |
| --- | --- | --- | --- |
| PLAN-D01 | 多版本文件确定最终方案 | P0 | 来源优先级及未修改条件保持 |
| PLAN-D02 | 活动长说明的末尾退款例外 | P1 | 条件、时限和引用完整性 |
| PLAN-D03 | 查当前官方通知并区分旧年份 | P2 | 年份、更新日期与结论可追溯 |
| PLAN-D04 | 缺页或缺日期资料中的未知信息 | P1 | 澄清与补料后结论更新 |

每次保存实际输入全文/文件、版本与入口、完整会话及真实来源。新会话不能保证长程记忆彻底清空，须如实记录记忆状态与已提供材料。合理追问、说明看不到文件或无法联网可以是正确行为。

<a id="plan-d01"></a>
### PLAN-D01 多版本文件确定最终方案

**分类与状态：** 主类D；辅助能力“工具、创作”；P0；状态待执行，等级待评。

**入口与上下文：** 主入口上传多文件；支持时使用文件内“问小微”作对照。系统应收到v1、v2和备注三份全文，以及用户明确的主方案选择，不能假设备注文件自动替代主方案。

**前提与素材：** 已读取现成[方案v1](../测试素材/工具06-10/TOL08/方案_v1.txt)、[方案v2](../测试素材/工具06-10/TOL08/方案_v2.txt)、[备注](../测试素材/工具06-10/TOL08/方案_v2_备注.txt)。可直接上传：v1预算120元、3人；v2预算180元、4人；备注明确“不替代主方案”，集合地点东门。上传失败则记录阻塞；改为粘贴全文只能验证纯文本版本理解，不宣称文件路径已测。

**口语开场：** “这次小组活动我改了两版。先用v2，备注只补地点，帮我列人数、总预算、人均预算和集合地点，每项说一下看的是哪个文件。”

**随结果选用的后续变化：**

1. “先别做收费通知，这只是预算，还没决定要不要收钱。”
2. “现在主方案改回v1，地点还用备注的东门，别把两版混在一起。”
3. “按现在这版给我一段活动说明，人数、预算和地点都带上。”
4. 如实际串版，指出对应文件名并让其复核；没有串版就无需反复质疑。

**测试者核对依据：** 首阶段v2：4人、180元、人均预算45元、东门。最终v1：3人、120元、人均预算40元、东门。没有指定收费规则，不能写成“每人必须交40元”。预算改变而地点未变，备注不提供人数或金额。

**候选失败与判级条件：** 少量表述不清、澄清后核心正确可为B；最终人数、预算跨版本混搭或错误收费通知通常考虑C；错版不自动判D，只有明确把不存在的句子、来源或页码编造成确定依据等，才核验D红线。一次到位且完整可记录A候选，复杂度及是否值得提交Good Case另评。

**不报为缺陷：** 首次询问哪个是主方案；指出备注名像v2但正文适用范围需确认；说明不能访问附件；对预算与收费主动区分。

**复现与单变量对照：** 相同文件和选择顺序重放；仅反转上传顺序但保持同样明确的主方案指令。必要时另用全文粘贴对照，保留原失败记录；不要以文件名排序替代实际明确指令。

**独有证据：** 三份原文件、实际上传次序、主方案两次选择、四字段来源表、最终说明。保存文件可读证据及完整截图，不只留最终一轮。

<a id="plan-d02"></a>
### PLAN-D02 活动长说明的末尾退款例外

**分类与状态：** 主类D；辅助能力“内容、工具”；P1；状态待执行，等级待评。

**入口与上下文：** 文件内问小微，或主入口上传完整说明。系统应获得包括最后“改期补充说明”的完整正文。若只选中了正文开头，就不能把未被提供的尾条款当漏读。

**前提与素材：** 已准备[读书营参与说明TXT](./配套素材/读书营参与说明.txt)，下方也是可直接复制的完整合成正文。上传支持的格式，记录实际字符数、段落数；TXT没有固定页码。当前只是正常活动说明，不声称已经有几十页长文。若要增加长度，只增加相关且互不矛盾的说明段落，每版都保留末条款；不靠乱码或机械重复撑长。素材中日期是虚构材料内容，判断使用材料给定的申请时刻，不读取“今天”作为暗含条件。

```text
校园读书营参与说明
第1条 参与者个人临时取消，已支付的材料费不退。活动原定2027年6月12日14:00至17:00，地点为校内阅读室。本说明中的材料费是已支付费用，不等同于活动预算。
第2条 报名时填写昵称和意向讨论组。活动使用自选主题分组，人数过多时由主持人协调。未提前选组的参与者可在签到时选择，不影响其已经确认的名额。
第3条 签到区会按报名昵称核对名单，再发放纸质材料。无需公开展示个人手机号；临时迟到者可以从侧门进入，由工作人员协助找到所在小组。
第4条 材料包包含讨论纸、便签及一张阅读节选。使用前可以先检查是否缺页，如有缺页向工作人员更换。参与者自行携带的书籍及个人笔记不计入材料费。
第5条 第一段讨论围绕节选中可直接找到的信息展开。记录者应区分原文、参与者转述和个人猜测。无法从材料确定的内容，可以列成待讨论的问题，不要求当场给出唯一答案。
第6条 第二段讨论由小组选择一个问题，分别整理赞成意见、不同意见和仍缺的依据。代表发言时请保留观点对应关系，不把某位参与者的意见写成全组一致结论。
第7条 室内活动须保持过道通畅。需要暂时离开时可告知同组同学，个人物品由本人保管。主办方提供常温饮用水，参与者也可自带水杯，不另行收费。
第8条 活动结束前会留出整理时间。各组回收未使用的纸张，把公共材料放回签到区。已经写有个人阅读笔记的纸张可由本人带走，工作人员不要求拍照上传。
第9条 活动后自愿填写体验反馈。反馈可选择匿名，只需描述活动内容和组织建议。不要求再次报名，也不将是否提交反馈作为领取材料或申请退款的额外条件。
第10条 如参与者需要咨询，应先说明报名昵称、问题类型和相关通知时间。对于本说明未涉及的情形，工作人员会说明当前无法确定的部分；不能把口头猜测当成已经公布的新规则。
改期补充说明：如主办方更改活动日期，参加者因新日期冲突无法到场，可在收到改期通知后48小时内申请材料费全额退款。本条只适用于主办方改期，优先于前述个人取消条款。
```

**口语开场：** 上传全文后：“我报了这个读书营，主办方临时改期了，新时间我去不了，交过的材料费还能退吗？”

**随结果选用的后续变化：**

1. “改期通知是2027年6月10日10:00收到的，我2027年6月11日18:00申请，都是北京时间。”
2. “把能支持你结论的原文那句摘出来，别自己添条件。”
3. “如果是我自己临时想取消，主办方没改期呢？这只是问另一种情况，不改前面那次事实。”
4. “给我一句解释两种情况的简短说明，不要把两条规则合成一条。”

**测试者核对依据：** 原案为主办方改期且通知后32小时申请，在48小时内，应可全额退款。反事实分支若仅个人临时取消，按第1条不退。原文没有教师签字、手续费、匿名反馈或再次报名等退款前提。引用尾条款应与原文一致；有真实页码才按页码定位，没有时用条目/段落即可。

**候选失败与判级条件：** 忽略末尾例外、时间算错导致核心退款结论错误，通常考虑C；轻微措辞问题但结论正确可为B；明确捏造不存在的强制条件、原文或页码，并以确定口吻冒充来源时才审D。不能仅因长版错短版对就宣称已定位“上下文截断”。

**不报为缺陷：** 初轮合理追问通知和申请时间；说明文件读取不完整；要求完整附件；不用页码而准确引用“改期补充说明”；将反事实问题与原案明确分开。

**复现与单变量对照：** 同文同入口重放；再仅移动尾条款到开头，保留其他文字与问题不变；或用只含第1条和尾条款的短版。三种版本分别标号，结果不互相覆盖。

**独有证据：** 实际文件及完整提取文本、首条与尾条位置、文件长度、申请时间计算、返回引文、反事实分支标记及全程截图。

<a id="plan-d03"></a>
### PLAN-D03 查当前官方通知并区分旧年份

**分类与状态：** 主类D；辅助能力“搜索、内容”；P2；状态待执行，等级待评。

**入口与上下文：** 已开放的微信搜索入口或主入口搜索；另选公众号内容入口时保存实际打开文章。记录测试时间、用户指定年份、检索词、返回来源及其可访问范围，不能把主入口自述“搜索了”当成后台调用证据。

**前提与素材：** 测试时再准备真实来源。选择自己确需了解且确有两个年份官方公告的活动；优先查本届比赛，若没有可比较的旧年同类公告，改选有完整官方资料的真实活动或标此分支阻塞。保存当年与往年原文、发布日期、更新日期、URL和截图；不自造官方公告，不提前把本地笔记的日期当作最新事实。本方案编制时未执行联网检索，不预填网址、当前截止时间或查询结果。

**口语开场：** “我想查[实际活动全称][目标年份]这一届的官方报名通知，报名到什么时候，交什么材料？给我能核对的官方出处。”先替换方括号并记录执行时刻。

**随结果选用的后续变化：**

1. “你看的页面是哪一年发的？这里的日期适用于哪一届？”
2. 打开实际旧年份公告后：“我又找到这篇旧通知，跟今年那篇分开对比一下，别混。”
3. “按我现在的时间[绝对日期、时间、时区]，还来不来得及？截止时刻没写清就说没写清。”
4. 只有来源不支持结论时，追问“这条要求在你给的页面哪段？”并核对落地页，不以搜索摘要代替全文。

**测试者核对依据：** 每个结论应对应其适用年份及实际来源；旧文只能用于明确标注的历史比较。当年官方通知未给具体时刻时，不要求模型捏造20:00或23:59；无法找到或无法访问应说明。测试时的原文快照优先于旧本地摘要，存在通知冲突则应指出而不是自行定夺。

**候选失败与判级条件：** 用错年份、结论遗漏重要限定通常考虑C；及时纠正且最终可用可能为B；明确虚构“官方原文有某句”、编造可证实不存在的引用，才按D红线审证。404、登录墙、网络超时、官方页面更新并不单独证明编造；来源失效应保留抓取时间和可复核证据。

**不报为缺陷：** 不同官方页面有真实冲突且如实提醒；找不到旧年资料；需要用户明确年份；无法联网时直接说明。第三方总结标明其身份、且没有假冒官方，不单凭身份就判缺陷。

**复现与单变量对照：** 优先在同一时段用相同查询重放；只增加目标年份或只切换入口，保持任务一致。内容变动应单独记为来源变更，不混入稳定复现次数；及时保存被引用的真实页面。

**独有证据：** 查询时间、年份、检索词、搜索结果、落地页全文/快照、页面适用范围、原URL和回答引用之间的逐项对应表。

<a id="plan-d04"></a>
### PLAN-D04 缺页或缺日期资料中的未知信息

**分类与状态：** 主类D；辅助能力“内容、工具”；P1；状态待执行，等级待评。

**入口与上下文：** 主入口先提供下列可见摘录，或文件入口先上传仅含该段的文件。初阶段系统未收到第二段，不能使用测试者私有完整版作为其应当已知的条件。若另用截图做变体，截图读取问题可关联C类，不重复建同一发现。

**前提与素材：** 已准备[仅第1页内容TXT](./配套素材/报名须知_仅第1页内容.txt)与[第2页补充内容TXT](./配套素材/报名须知_第2页补充内容.txt)，按顺序分阶段提供；文件名表示模拟页内容，不代表实际分页。下方文本也可直接复制。若另做两页文档，真实分页和页码需检查后再记录；TXT路径不称已验证PDF缺页能力。

```text
仅先提供这一段
校园阅读分享报名须知 第1页摘录
对象：本校学生。报名时填写昵称、年级和意向场次。
名额满后进入候补，释放名额按候补顺序通知。
截止日期与材料补充要求请见后页。
```

```text
合理要求补充后才提供这一段
校园阅读分享报名须知 第2页补充
报名截止：2027年6月11日18:00，北京时间。
未满18岁的参与者需要监护人确认。
已报名者现场核对昵称后领取材料，候补者按通知参加。
```

**口语开场：** 只发第一页：“这个什么时候截止？我报名需要找老师签字吗？”

**随结果选用的后续变化：**

1. 对方要求补页时再发第二页：“后面这页找到了，按现在收到的这两页帮我确认。”
2. “我已经19岁了，准备2027年6月11日17:00提交，都是材料里的北京时间，来得及吗？”
3. “那还需要教师签字吗？请区分文件写了什么，和你觉得可能要什么。”
4. 如果初轮擅自给出日期，先追问来源；补页后检查能否更正，而不把原先猜测当成已证事实。

**测试者核对依据：** 第一页不能确定截止日期，提问或说明未知正确。第一页没有教师签字要求，但由于后页缺失，应避免对完整材料要求作过度保证。补齐后可确定6月11日18:00截止，17:00尚早1小时；19岁不适用未满18岁监护人条件。两段均没有统一教师签字要求，应表述“这两页未见此要求”，不替真实主办方保证任何未提供规则。

**候选失败与判级条件：** 在缺信息时无依据确定截止时间、补料后仍沿用旧猜测或误用未成年条件，核心结论错误通常考虑C；澄清后及时修正且整体可用可能为B；明确把第一页不存在的日期或教师签字句子作为确定原文，才核验D档编造。合理未知不是Bad Case。

**不报为缺陷：** 请求后页、提醒资料不完整；先不给确定日期；要求确认是否还有附件；不用模型猜对的偶然日期证明它读到了未给内容。

**复现与单变量对照：** 新会话保持记忆状态可比，仅对比“先缺后补”与“一次给齐两段”。若换为真实两页文件，保留当次上传的确切页集，不能用另一完整版作为反证。

**独有证据：** 首轮实际只提供第一页的证明、测试者完整资料、补页时刻、每轮来源说明、对未知到已知的更新，以及私有答案没有提前输入的记录。

## 与现有方案的复用及去重

- PLAN-D01直接复用TOL08的三份已存在文件，关联OPT-019/OPT-022。版本混搭、错误收费推断可分别记录事实，但是否同类需按触发与表现比较，不能只按编号计数。
- PLAN-D02承接OPT-020末尾例外与OPT-021引用真实性；新增完整正常活动说明，文件仍须按实际保存与上传确认。
- PLAN-D03对应OPT-023/OPT-024，保留真实来源与当时版本，不将网络失败算成模型编造。
- PLAN-D04与OPT-018信息不完整时的处理相关，但本案主测文本/文件；换成图片属于跨模态对照，不自动产生新的可计分问题类。

依据：参赛指南2.1—2.2、3.1—3.6、4.4—4.6、5.2、6.2；培训已核对的真实任务、约束、引用与完整证据要求。AI纪要对后段提问的改写不作为已获官方认可的测试承诺。
