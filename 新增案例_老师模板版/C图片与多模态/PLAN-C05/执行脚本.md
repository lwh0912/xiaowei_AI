# PLAN-C05 截断纵轴图的增长量与增长率

**状态：待执行；不是已发现的Bad或Good Case。** 编制：2026-10-29。主场景：C 图片与多模态；执行顺序：P0（非严重度）。

## 任务与前提

识别图中100与110人；算出增加10人、相对前月增长10%；区分截断纵轴后的可见柱高与实际人数倍数。

建议入口：主入口上传原始PNG；实际附件接收状态待核。表单入口与平台依据实测选择，本稿不预填为已执行。

只上传输入材料/截断轴图.png；隐藏测试者核对答案。图为程序绘制的合成柱状图，轴从90开始，数值标注清晰。

输入图片：[截断轴图.png](./输入材料/截断轴图.png)、[零起点图.png](./输入材料/零起点图.png)。按步骤上传，勿提前混用。

## 可直接使用的执行脚本

每次等待真实回复再决定下一步；合理澄清如实保留。以下是计划话术，不是已有会话。

1. 【上传图片后发送】这是我们两个月的报名人数。请读出两个月人数、增加多少人、增长百分比，并解释图形看起来的差别。

2. 【发送】帮我把它写成一句活动复盘文案，保留具体数据。

3. 【发送】有人说“后一个柱子看着是前一个的两倍，所以人数翻倍了”。只根据这张图，这个判断对吗？

4. 【发送】给我最终文案，并说明百分比用哪个月作分母。

## 分支与复现

前三步为同一读图任务的自然核对；若识别错数，先询问图上数字，保存其读数以区分OCR与计算问题。

单变量对照上传零起点图.png，数值相同、轴不同，计算结果应相同；不能把两张图的差异都归因模型推理。

先完成一次完整探索；发现值得核实的差异，再做同条件复现和一个单变量对照。次数按实际记录，不预设必现；变体与原条件分开统计。
